CALENDRIER 60 JOURS - PWA
==========================
Fichiers : index.html, manifest.webmanifest, sw.js, icons/

Pour l'utiliser comme PWA, héberger ce dossier sur une adresse HTTPS.
Sur Windows : ouvrir l'adresse avec Edge ou Chrome puis choisir Installer l'application.
Sur iPhone : ouvrir l'adresse dans Safari > Partager > Sur l'écran d'accueil.
